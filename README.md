# 보이스 프롬프터 (auto_prompt)

내 **목소리를 듣고 대본을 따라 스크롤**해 주는 프롬프터. 정해진 속도로 글자를 미는 게 아니라, 지금 어디를 읽는지 실시간으로 추적해서 그 위치를 화면에 맞춘다. 한국어 전용으로 튜닝했고, **릴스부터 10분 분량까지** 무리 없이 커버한다.

- **두 가지 모드.** 🎙 음성 따라가기(내 목소리 추적) + ⏱ 자동 스크롤(마이크 없이 일정 속도로, iPad 포함 모든 기기).
- **완전 무료 · API 키 없음.** 전 구성이 오픈소스이고 브라우저 안에서 돈다.
- **오프라인 가능.** Vosk 엔진은 인터넷 없이 기기에서 인식한다.
- **긴 대본 OK.** 커서 주변만 보는 윈도우 방식이라, 10초든 10분이든 비용이 일정하다.

> **이 앱은 `kyulolong.com/prompt/` 에 얹혀 있다.** 경로 위에 사는 앱이라 따로 지켜야 할 것들이 있다 —
> base·끝 슬래시·파비콘·SEO·Supabase·nginx·배포 순서. 손대기 전에
> [규로롱 서비스 체크리스트](https://github.com/Kyulolong/kyulolong-site/blob/main/docs/SERVICE-CHECKLIST.md)를 읽을 것.
> 거기 적힌 함정은 대부분 이 레포에서 한 번씩 밟은 것들이다.

---

## 빠른 시작

```bash
npm install
npm run dev          # http://localhost:5173 (데스크톱 Chrome 권장)
```

1. 대본을 붙여넣고 (또는 “샘플 넣기”) **시작**을 누른다.
2. 마이크 권한을 허용한다.
3. 읽기 시작하면 현재 단어가 하이라이트되고 화면이 따라 내려온다.

### 오프라인(Vosk)으로 쓰려면

먼저 한국어 모델을 한 번 받는다 (~82MB, 무료):

```bash
npm run get-model
```

그런 다음 시작 화면에서 음성인식을 **Vosk · 오프라인**으로 고른다.

---

## 두 가지 음성인식 엔진

| 엔진 | 오프라인 | 준비 | 비고 |
| --- | --- | --- | --- |
| **Web Speech** | ✗ (구글 클라우드) | 없음 — 바로 사용 | 데스크톱 Chrome/Edge 전용. ~60초마다 자동 종료되지만 자동 재시작으로 이어감 |
| **Vosk** | ✓ 완전 오프라인 | `npm run get-model` | 어느 브라우저든 WASM으로. 세션 시간 제한 없음 → 긴 촬영에 적합 |

둘 다 STT 정확도가 완벽할 필요는 없다. **대본을 이미 알기 때문에**, 위치를 잡을 만큼만 맞으면 된다.

---

## 어떻게 동작하나

```
mic → STT 어댑터 (Web Speech | Vosk)   ← 갈아끼우는 부품
        │  최근 단어들
        ▼
     정렬 엔진 (자모 단위 윈도우 매칭)    ← 핵심, STT를 모른다
        │  현재 토큰 index + 읽기 속도
        ▼
     스크롤 컨트롤러 (rAF 이징 + word creep)
        ▼
     프롬프터 화면 (현재 단어 하이라이트)
```

**핵심 아이디어:** 받아쓰기가 아니라 *이미 아는 대본에 목소리를 정렬*시키는 문제다. 그리고 비교를 **자모(自母) 단위**로 한다 — STT가 받침 하나를 틀려도 편집거리 1로 끝나서, 한국어 인식이 깨지던 지점을 흡수한다.

동작 처리(전부 점수 규칙으로 통일):

- **낭독** → 창 안 매칭이 커서를 전진
- **애드립/의역** → 점수 미달 → 위치 유지 (드리프트 없음)
- **멈춤** → 입력 없음 → creep 정지, 위치 유지
- **건너뛰기** → 창 안 앞쪽 매칭 → 점프
- **다시 읽기** → 살짝 뒤 구간 무벌점 허용
- **완전히 길을 잃음** → 역색인으로 대본 전체에서 재탐색 후 복귀

숫자·영어도 처리: `2025` ↔ `이천이십오`를 같은 자모로 정규화해서 어느 쪽으로 인식돼도 맞춘다.

## 코드 구조

```
src/
  korean/
    jamo.ts       자모 분해 · 숫자→한글 · 정규화 (의존성 없음)
    script.ts     대본 → 토큰 + 자모 스트림 + 역색인
  engine/
    align.ts      윈도우 정렬 엔진 (핵심) + 재탐색
    scroll.ts     rAF 이징 + word creep 스크롤
  stt/
    types.ts      SttEngine 인터페이스 (swap seam)
    webspeech.ts  Web Speech 엔진 (자동 재시작 포함)
    vosk.ts       Vosk 오프라인 엔진 (lazy import)
  ui/
    useController.ts  STT→정렬→스크롤 배선
    Prompter.tsx / Editor.tsx / Controls.tsx / App.tsx
```

## 튜닝 노브

- 정렬 민감도: [src/engine/align.ts](src/engine/align.ts) `DEFAULT_CONFIG` — `accept`(수용 임계값), `back`/`forwardBase`(윈도우 크기), `lostThreshold`, 그리고 위아래 튐 방지용 `backwardPenalty`(뒤로 튐 억제)·`forwardPenalty`(멀리 순간이동 억제).
- 스크롤 느낌: [src/engine/scroll.ts](src/engine/scroll.ts) `DEFAULT_SCROLL` — `spring`(이징), `creepCapTokens`(예측 전진 한도), `readingLineFrac`(읽는 줄 위치).

화면에서 글자 크기·읽는 줄 위치·거울 모드는 실시간으로 조절된다. 대본과 설정은 브라우저에 자동 저장된다.

## 지금 상태 & 한계

MVP다. 노트북(데스크톱 Chrome)에서 바로 쓸 수 있는 수준을 목표로 했다.

- 숫자는 한자어 읽기(사이노-코리안)만 정규화한다. 고유어 수(하나·둘…) 표기는 아직.
- iPad/모바일 Safari에서의 Vosk WASM 지연·발열은 별도 검증이 필요하다(이 버전은 데스크톱 우선).
- 정렬 상수는 실제 낭독 녹음으로 더 다듬을수록 좋아진다.
